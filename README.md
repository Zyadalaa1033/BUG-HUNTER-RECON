# BUG-HUNTER-RECON
BUG HUNTER RECON هو ملف HTML تفاعلي يعمل مباشرةً في المتصفح بدون تثبيت أو خادم، يجمع أكثر من 750 أمر جاهز لـ 90+ أداة احترافية مقسّمة على 3 مراحل رئيسية (Recon, OSINT, Search Dorks)، مع محرك قوالب ديناميكي يُحدّث جميع الأوامر فورياً عند تغيير الهدف، وسلاسل Pipelines جاهزة تربط الأدوات تلقائياً — كل ذلك في ملف واحد لا يحتاج إنترنت.
